# typryx v0.6.1

The service and its image are built with Go 1.27.4, which fixes GO-2026-6859 in `net/http`. The v0.6.0 image was built with Go 1.27.3. No route, setting or wire format changes.

Tag: `v0.6.1`. The image is `ghcr.io/taipanbox/typryx:v0.6.1`. There is no moving tag (no `latest`, no `main`).

## Changed since v0.6.0

- #42, `build: Go 1.27.4 for GO-2026-6859`. The `toolchain` line in `go.mod`, the CI `go-version` and the Go version of the `Dockerfile` move to Go 1.27.4. No other commit lies between the v0.6.0 tag and this release.

## Upgrade

Pull `ghcr.io/taipanbox/typryx:v0.6.1` and restart. No configuration changes. To roll back, run v0.6.0 again.
