# Typryx 0.4.1

A patch release for the wardryx proxy's counting and logging of truncated tool
calls, plus the toolchain, dependency and CI moves since 0.4.0. The proxy's
behaviour on the wire is unchanged: a truncated call is still forwarded untouched,
and typryx is still never asked about it.

## Fixed

- **A truncated tool call is counted and logged (#27).** A tool call whose
  arguments were cut off is now counted in `Stats` under
  `skipped:arguments_truncated`, and it writes one log line that names the reason
  and carries no argument. Before, the skip was invisible. Invariant 41 and the
  README describe the behaviour.
- **The skip log line is rate-limited (#27).** The first skip is logged at once,
  then at most once per ten seconds. Each line says how many skips it stands for
  since the line before, and the counter in `Stats` stays exact. A clock that steps
  backwards logs again rather than going quiet.
- **The README says what a missing signal costs (#27).** Whether a call without a
  signal is held is wardryx's policy, set by `when_absent: hold` in wardryx, and
  the README no longer says that a missing signal cannot cost anything.

## Changed

- **Go 1.27.2 (#23).** The module's toolchain, the CI `go-version` and the
  Dockerfile's Go argument move together, and this release is built with 1.27.2.
- **agent-stack-go v1.1.0 (#20).** The shared event library moves to v1.1.0. The
  build and the tests pass against it.
- **Estate secret scan in CI (#24).** The reusable scanner runs on every pull
  request and on every push to `main`. No runtime change.

## Documentation

- The README names `gosec` and `govulncheck` in its gate list, labels the template
  digests as command output (#25), and says what its two test counts measure (#26).
- The README lists five starter templates and the current teeth count, and says
  that the launchers carry typryx (#21).

## Upgrade notes

- Nothing to configure. No variable, route, response shape, journal line or
  training line changed.
- A proxy that logged nothing for a truncated call now logs one line per skip,
  rate-limited as above. A log pipeline that alerts on any line from the proxy
  will see these.
- The image is `ghcr.io/taipanbox/typryx:v0.4.1`, per tag as before.
