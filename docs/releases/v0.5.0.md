# Typryx 0.5.0

This is a minor release, not a patch, because the move to agent-stack-go v2 (below) changes how event stream files are created.

## Upgrade first: the event stream file

Since agent-stack-go v2, a stream file this service creates is mode `0640`, not `0644`: the owning account and its group can read it, and no other account can. A new stream file is created only in a directory this service's account owns. An existing file is opened as it is.

A bus directory that is shared between services and not owned by typryx's account gets no new stream, unless each file is created beforehand by the uid of the service that writes it. Before you start 0.5.0, check who owns the bus directory and the mode of each stream file in it. stack-single creates its files this way; a deployment that does not must do the same.

## Upgrade: the image

Pull `ghcr.io/taipanbox/typryx:v0.5.0` in place of `v0.4.1`. The configuration and the stored state are the same. The image size in the README is the 0.4.1 measurement and was not re-measured for this release.

## Fixed

- **The proxy forwards the enforcement point's key only to the configured wardryx (#32).** The proxy still forwards the caller's `Authorization` header to wardryx, since it is the enforcement point's own key and wardryx needs it to bind the agent. What changes is where that header can go: the default transport dials only the configured upstream's host and port and refuses any other. The proxy keeps no key of its own.

## Changed since v0.4.1

Commits between the 0.4.1 tag and this release:

- #32, the proxy fix above.
- #33, `chore(deps): move agent-stack-go to the v2 module, v2.0.0`. The shared wire-type import moves to `github.com/TAIPANBOX/agent-stack-go/v2`. This is the change described under Upgrade first.
- #34, `ci(release): sign the image in the legacy format policy-controller reads`. The image sign step adds `--new-bundle-format=false --use-signing-config=false`, with a comment above it, because the cluster admission controller (policy-controller v0.15.1) reads only the legacy `.sig` tag. cosign stays at v3.1.3.
- agent-stack-go pins v1.2.0 (#30) and v1.3.0 (#31), before the v2 move.
- README: the install lines name the published image and tag (#29).
